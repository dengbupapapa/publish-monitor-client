# Spec Delta

## ADDED Requirements

### Requirement: 两侧标签必须使用统一的稿件术语

对照区表头、单侧行的空侧占位、差异记录卡片三处指代两侧的标签 MUST 统一使用「内部稿件」与「发布稿件」：「内部稿件」指经过内部审核的那一侧稿件，「发布稿件」指对外发布的那一侧稿件。

详情页 MUST NOT 再以「参考侧」「发布侧」指代两侧。术语 MUST 与列表页「内部稿件名」「发布稿件名」的列名保持一致，使同一对象在全站只有一个叫法。

#### Scenario: 对照区表头标签

- **WHEN** 一条结论的详情渲染完成
- **THEN** 对照区两列表头分别显示「内部稿件」与「发布稿件」，不出现「参考侧」或「发布侧」

#### Scenario: 单侧行的空侧占位

- **WHEN** 某一行只有一侧有内容
- **THEN** 空的那一格显示「内部稿件无对应内容」或「发布稿件无对应内容」，标注的是空的那一侧

#### Scenario: 记录卡两侧标签

- **WHEN** 详情包含差异记录
- **THEN** 每张记录卡的两侧标签分别为「内部稿件」与「发布稿件」，处数与摘要落在标签所指示的那一侧

### Requirement: 页头必须保留返回与版本信息且不展示结论编号

详情页头 MUST 提供返回列表的入口；详情返回坐标版本时 MUST 在页头显示版本号。

页头 MUST NOT 以可见文本展示结论编号。结论编号 MAY 继续存在于页面地址中以支撑直达与刷新，也 MAY 在列表页以提示形式暴露以便追溯。

#### Scenario: 打开详情页头

- **WHEN** 使用者打开一条已知编号的结论详情
- **THEN** 页头显示返回列表入口与坐标版本，且不出现「结论 #编号」文本

#### Scenario: 坐标版本缺失

- **WHEN** 详情未返回坐标版本
- **THEN** 页头只显示返回列表入口，不出现版本占位或空白塌陷

#### Scenario: 编号仍可追溯

- **WHEN** 使用者需要追溯当前页面是库中的哪一条结论
- **THEN** 结论编号仍出现在页面地址中，列表页对应行的提示仍可给出该编号
