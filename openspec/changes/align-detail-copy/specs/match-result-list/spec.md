# Spec Delta

## ADDED Requirements

### Requirement: 结果列的依据说明必须沿用稿件术语

「疑似未审」「未完成比对」等结果列的依据说明 MUST 用「内部稿件」与「发布稿件」指代两侧，MUST NOT 使用「参考侧」「发布侧」一类旧称，使列表页与详情页对同一对象只有一个叫法。依据说明的可发现性要求不变。

#### Scenario: 疑似未审的依据说明

- **WHEN** 一条结论的匹配态为不匹配
- **THEN** 该行「疑似未审」的依据说明指明发布稿件未匹配到内部稿件，不出现「发布侧」或「参考侧」

#### Scenario: 与稿件名列一致

- **WHEN** 使用者同时阅读一行的稿件名列与结果列的依据说明
- **THEN** 两处对两侧的称呼一致，不需要在脑中做术语映射
