# Spec Delta

## ADDED Requirements

### Requirement: 正文中的外部图片必须真实显示，不得被图床防盗链替换为占位图

两侧正文中的图片 MUST 呈现图片本身的真实内容，MUST NOT 显示图床针对非白名单来源返回的占位图（例如微信公众平台的「此图片来自微信公众平台 未经允许不可引用」）。

同一张图片 MUST 在应用内打开与在浏览器地址栏直接打开时呈现相同内容，MUST NOT 因应用自身所在的域名、端口或运行方式（开发服务器 / 生产站点）而呈现不同内容。

该处理 MUST 只作用于正文图片的取图行为，MUST NOT 改变页面其余请求携带来源信息的方式。

未接入防盗链的图片站点 MUST 保持原有显示效果，MUST NOT 因该处理出现加载失败或尺寸异常。

#### Scenario: 微信图床图片

- **WHEN** 正文包含来自微信公众平台图床的图片，使用者打开该结论详情
- **THEN** 图片位置显示图片本身的真实内容，不出现「未经允许不可引用」占位图

#### Scenario: 图片类差异落在真实图片上

- **WHEN** 一条图片类差异记录命中正文中的某张外部图片
- **THEN** 该图片显示真实内容，并仍被轮廓类标记标出，轮廓标记不落在占位图上

#### Scenario: 其它图片站点不受影响

- **WHEN** 正文包含来自不校验来源的图片站点的图片
- **THEN** 图片正常显示，尺寸与布局与处理前一致

#### Scenario: 页面其余请求不受影响

- **WHEN** 使用者打开详情页，页面发起数据接口与静态资源请求
- **THEN** 这些请求携带来源信息的方式与处理前一致，不因图片处理被一并改变
