# Proposal

## Why

对照详情页有两个可用性问题：表头列在滚动容器外、正文行在容器内，正文出现纵向滚动条（Windows 上约 17px）后两侧 `1fr` 列宽不再相等，表头与正文列肉眼可见地错位；同时连线上只有颜色区分变化方向，色弱或不熟悉配色的人无法一眼读出一条线代表「新增 / 删除 / 修改」，需要在连线上补充可读的标注。

## What Changes

- **表头对齐**：把对照区表头（两侧标题区）从滚动容器外移入 `.rows-scroll` 内，改用 `position: sticky; top: 0` 固定在列上方。表头与正文行共用同一宽度上下文（含滚动条占位），任何滚动条形态、窗口缩放下列宽都严格一致，且随横向滚动同步移动。
- **连线标注改为行内悬停标签**：不在 SVG 连线上直接画字，改为在**发布稿（input）侧单元格左上角**加绝对定位的小字标签，显示落在此行的差异记录变化方向（新增 / 删除 / 修改 / 未知如实标注）。鼠标移入该行时显示，同一行多条记录的标签横向排列；字号极小、绝对定位、不参与布局，不影响正文内容与原有行高、间距。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `match-result-detail`: 「标题必须分列显示且不参与对比行」要求增加表头必须与正文列宽严格对齐（sticky 实现进入滚动容器仍满足原有不动性约束）；「差异连线必须按记录配对并可跨行」要求增加变化方向必须在发布稿行左上角以悬停小字标注、行内多记录标签横向排列且不影响排版。

## Impact

- `src/components/diff/DiffWorkspace.vue`：表头移入滚动容器并加 sticky 定位、调整 z-index 层级；行标签的渲染入口（可在 `DiffRow.vue` 增加标签层）。
- `src/styles/diff.css`：表头 sticky 样式、行左上角标签样式（绝对定位、极小字号、横向 flex 排列、悬停显隐）。
- `src/diff/wires.js`：不改动连线几何，仅为标签提供每行的 kind 信息可能需要复用 `records` / 锚点统计；`DiffWorkspace` 已有 `anchorRows` 统计，可扩展出每行 → kind 列表。
- 不改后端接口与数据结构；不改变高亮、连线几何、联动、滚动等既有行为。
