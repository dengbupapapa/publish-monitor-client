# Spec Delta

## MODIFIED Requirements

### Requirement: 标题必须分列显示且不参与对比行

两侧标题 MUST 分别显示在各自正文列正上方的固定区域并与列宽对齐，标题 MUST NOT 占用对比行、MUST NOT 参与逐行对齐、高亮与连线。

表头 MUST 与正文行处于同一宽度上下文内取列宽：正文出现纵向滚动条、横向溢出或窗口缩放时，表头列 MUST 仍与正文列严格对齐，MUST NOT 因滚动条占位产生错位。正文横向滚动时，表头 MUST 随同一横向滚动位置移动。

某侧标题缺失时 MUST 显示占位文本，MUST NOT 留空导致表头塌陷。

#### Scenario: 两侧标题

- **WHEN** 详情返回两侧标题
- **THEN** 两个标题分别出现在参考列与发布列正上方，滚动正文时保持可见

#### Scenario: 某侧标题为空

- **WHEN** 某一侧标题为空字符串
- **THEN** 该侧标题位置显示占位文本，另一侧布局不受影响

#### Scenario: 正文出现纵向滚动条时表头仍对齐

- **WHEN** 正文高度超出视口使对照区出现纵向滚动条
- **THEN** 表头两列与正文两列的边界严格对齐，两侧列宽一致，无滚动条占位造成的横向错位

#### Scenario: 正文横向溢出时表头同步滚动

- **WHEN** 某行内容宽度超出列宽使对照区出现横向滚动条
- **THEN** 表头与正文随同一横向滚动位置移动，表头列始终覆盖在对应正文列上方

#### Scenario: 窗口缩放后仍对齐

- **WHEN** 使用者缩放窗口或浏览器缩放比例改变
- **THEN** 表头列与正文列保持对齐，不出现固定像素差

### Requirement: 差异连线必须按记录配对并可跨行

对每条差异记录，页面 MUST 把两侧命中的高亮按纵向顺序一一配对并画出连线，配对 MUST 只依据该记录自身声明的两侧区间，MUST NOT 依据两侧内容是否被排在同一个行里。

同一条记录的两侧高亮位于不同行时，连线 MUST 跨行连接。当一侧高亮数量少于另一侧时，多出的高亮 MUST 画成只指向单侧的半线并使用与实心端点可区分的空心端点。

连线颜色 MUST 随变化方向区分，且 MUST 与高亮颜色一致。

连线 MUST 随布局变化（行高变化、图片加载完成或失败、窗口尺寸变化）重新贴合高亮位置，MUST NOT 因滚动而改变形状或相对位置。

#### Scenario: 两侧高亮同行

- **WHEN** 一条记录的两侧高亮落在同一行
- **THEN** 该行中缝出现一条连接两侧高亮的连线，两端为实心端点

#### Scenario: 两侧高亮不同行

- **WHEN** 一条记录在参考侧的高亮位于第 3 行、在发布侧的高亮位于第 7 行
- **THEN** 页面画出跨越第 3 至第 7 行的中缝连线

#### Scenario: 一侧高亮更多

- **WHEN** 一条记录在发布侧有 3 处高亮、参考侧有 1 处
- **THEN** 按纵向顺序第 1 处连成实线，其余两处为指向发布侧的虚线半线，参考侧端点为空心

#### Scenario: 图片加载改变行高

- **WHEN** 行内图片加载完成或失败导致行高变化
- **THEN** 连线重新贴合新的高亮位置，行对齐与滚动位置仍然有效

## ADDED Requirements

### Requirement: 行的变化方向必须以悬停标签标注

对照区 MUST 在发布稿侧单元格的左上角为差异记录提供变化方向标签：每条记录的标签 MUST 出现在该记录连线发布稿端点所在行的发布稿单元格上，MUST NOT 出现在无关行。

标签 MUST 以绝对定位呈现、字号极小，MUST NOT 参与布局，MUST NOT 改变正文内容、行高与既有间距；标签与连线、高亮使用同一变化方向语义。

标签 MUST 在指针悬停该行时可见；未悬停时 MUST 不显示或以不干扰阅读的方式呈现。同一行的多条记录标签 MUST 横向依次排列，MUST NOT 相互遮挡正文首行内容。

变化方向文案 MUST 与记录卡一致（新增 / 删除 / 修改）；变化方向未知时标签 MUST 如实标注，MUST NOT 冒充已知方向。

#### Scenario: 悬停显示标签

- **WHEN** 指针移入一行发布稿单元格
- **THEN** 该行对应记录的变化方向标签出现在该单元格左上角，正文内容与行高不变

#### Scenario: 未悬停不干扰阅读

- **WHEN** 指针不在任何行上
- **THEN** 标签不显示，对照区呈现与改动前一致的排版

#### Scenario: 一行多条记录

- **WHEN** 同一行有两条以上记录的连线发布稿端点落在此处
- **THEN** 多个标签在左上角横向依次排列，互不重叠且不遮挡正文

#### Scenario: 未知变化方向

- **WHEN** 一条记录的变化方向不是新增、删除或修改中的任何一种
- **THEN** 标签如实标注该记录的方向而不是显示为已知方向

#### Scenario: 布局变化后标签归组正确

- **WHEN** 行高变化或连线重新贴合导致记录发布稿端点所在行改变
- **THEN** 该记录的标签随端点移动到新的行，不残留在旧行
