# Spec Delta

## ADDED Requirements

### Requirement: 页头只保留过滤控件且不展示页面标题与整页说明

列表页页头 MUST NOT 展示页面标题（例如「稿件核查结论」）与整页说明文案（例如「只读视图：按服务端分页与过滤列出对比结果」）。页头 MUST 只承载列表的过滤控件。

页头的过滤控件 MUST 保持齐备：关键词检索与「仅看疑似未审或有差异」勾选项 MUST 全部保留在原位，MUST NOT 因移除标题与说明而减少、隐藏、合并或降级为其它形态。控件的宽度、先后顺序、彼此间距与交互（输入防抖、勾选写缓存、切换回到第一页）MUST 与移除前一致。

过滤控件 MUST 在页头内右侧对齐并占据页头整行宽度。移除标题与说明 MUST NOT 在页头留下空容器、空白占位或多余的垂直空白。

移除页头标题 MUST NOT 影响浏览器标签标题：页面 MUST 仍以既有名称作为标签标题，MUST NOT 清空或退回文件名。

#### Scenario: 打开列表页页头

- **WHEN** 使用者打开列表页
- **THEN** 页头不出现「稿件核查结论」或「只读视图：…」这类标题与说明文字，页头只有关键词检索与「仅看疑似未审或有差异」勾选项

#### Scenario: 控件在移除文案后仍齐备且右对齐

- **WHEN** 使用者查看收缩后的页头
- **THEN** 关键词检索在前、勾选项在后，两者整体贴近页头右缘，控件宽度与间距保持移除前的数值，检索与勾选行为不变

#### Scenario: 页头不塌陷

- **WHEN** 标题与说明被移除
- **THEN** 页头不残留空容器或占位空白，过滤控件下方与表格之间的间距与移除前一致

#### Scenario: 浏览器标签仍可识别页面

- **WHEN** 使用者切到浏览器标签页视图
- **THEN** 标签标题仍显示该页面的既有名称，不因移除页头标题而变为空或退回文件名
